## Quick Definition
Noise cancellation is an audio processing technique that actively or passively reduces unwanted ambient sound. It works by generating an anti-noise signal that interferes destructively with the incoming noise, thereby enhancing the clarity of desired audio signals.

## Key Concepts
- Active Noise Cancellation (ANC) → Uses electronics to create anti-noise waves.
- Passive Noise Cancellation (PNC) → Relies on physical sound insulation.
- Destructive Interference → Wave phenomenon where two waves cancel each other out.
- Digital Signal Processor (DSP) → Hardware for real-time audio signal manipulation.
- Adaptive Filtering → Algorithms that dynamically adjust to changing noise environments.
- Signal-to-Noise Ratio (SNR) → A measure of signal strength relative to background noise.
