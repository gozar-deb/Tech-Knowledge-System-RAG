## Quick Definition
Statistical Signal Processing (SSP) is a field that applies statistical methods to analyze and interpret signals, particularly when they are corrupted by noise or uncertainty. It models signals as random processes to develop optimal algorithms for tasks like estimation, detection, and prediction, enabling robust information extraction from noisy data.

## Key Concepts
- Random Processes → Mathematical models for systems evolving stochastically.
- Estimation Theory → Inferring unknown signal parameters from noisy observations.
- Detection Theory → Determining signal presence or absence in noise via hypothesis testing.
- Spectral Estimation → Estimating power spectral density of random processes.
- Adaptive Filtering → Filters that adjust characteristics dynamically for optimal performance.
- Kalman Filter → Optimal recursive algorithm for state estimation in dynamic systems.
- Wiener Filter → Optimal linear filter minimizing mean square error for signal estimation.
- Hidden Markov Models (HMMs) → Statistical models for systems with hidden states.
- Bayesian Inference → Updating hypothesis probabilities with new evidence using Bayes' theorem.
- Signal Modeling → Representing signals using mathematical models for analysis.
