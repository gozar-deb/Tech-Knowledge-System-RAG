## Quick Definition
Authentication protocols are structured rules for verifying the identity of users or systems accessing resources. They ensure that an entity is legitimate, acting as a foundational layer for access control and overall system security. These protocols often rely on cryptographic methods to secure the identity verification process.

## Key Concepts
- Credential: Information used to verify identity, such as passwords, tokens, or biometric data.
- Identity Provider (IdP): A service that manages and authenticates user identities.
- Service Provider (SP): An application or service that consumes authentication from an IdP.
- Multi-Factor Authentication (MFA): Using multiple distinct methods to confirm identity.
- Single Sign-On (SSO): Authenticate once to access multiple independent applications.
- Federated Identity: Linking user identities across different security domains.

## Tools

| Tool | Type | Purpose |
|------|------|---------|
| OAuth 2.0 | Framework | Authorization delegation for web/mobile apps |
| OpenID Connect | Protocol | Identity layer on top of OAuth 2.0 for user authentication |
| SAML | Protocol | XML-based standard for exchanging authentication and authorization data |
| Kerberos | Protocol | Network authentication protocol for client-server applications |
| FIDO2 | Standard | Passwordless authentication using biometrics or security keys |
| Active Directory | Infrastructure | Microsoft's directory service for identity and access management |
