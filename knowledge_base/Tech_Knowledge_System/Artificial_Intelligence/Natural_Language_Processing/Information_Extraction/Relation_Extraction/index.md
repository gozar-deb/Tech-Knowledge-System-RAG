## Quick Definition
Relation Extraction is a core Natural Language Processing task that identifies and categorizes semantic relationships between entities within text. It transforms unstructured text into structured relational data, often forming the backbone of knowledge graphs and intelligent systems.

## Key Concepts
- Entity Recognition → Pre-requisite task to identify and classify named entities in text.
- Semantic Relationships → The specific types of connections between entities (e.g., 'employs', 'located_in').
- Knowledge Graphs → Structured representations of facts, where nodes are entities and edges are relations, often populated by RE.
- Distant Supervision → A method to automatically generate training data for RE by aligning text with existing knowledge bases.
- Transformer Models → State-of-the-art deep learning architectures that excel at capturing contextual information for RE.
- Open Information Extraction (OpenIE) → Extracts relations without a pre-defined schema, discovering novel relationships.
