## Quick Definition
Image segmentation is a computer vision technique that divides a digital image into multiple segments or regions, often to isolate objects or other relevant information. This process simplifies image analysis by changing its representation to something more meaningful and easier to interpret.

## Key Concepts
- Semantic Segmentation → Assigns a class label to every pixel.
- Instance Segmentation → Identifies and delineates each distinct object instance.
- Panoptic Segmentation → Combines semantic and instance segmentation for comprehensive scene understanding.
- Masking → Creating a binary image to highlight specific regions of interest.
- Region of Interest (ROI) → A selected subset of an image for focused analysis.
- Ground Truth → Manually annotated data used for training and evaluating models.
- Pixel-level Classification → Assigning a category to each individual pixel.
- Boundary Detection → Identifying precise borders between objects or regions.
