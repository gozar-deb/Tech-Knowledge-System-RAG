## Quick Definition
Symbolic planning uses explicit logical representations to generate action sequences for goal achievement. Neuro-symbolic planning integrates neural networks with these symbolic methods, combining data-driven learning with structured reasoning to create more robust, adaptable, and interpretable AI systems.

## Key Concepts
- Symbolic AI → AI based on explicit knowledge and logical rules.
- Neuro-Symbolic AI → Hybrid AI combining neural learning with symbolic reasoning.
- Automated Planning → Generating action sequences to reach a goal state.
- PDDL → Standard language for defining planning problems.
- Knowledge Representation → How information is stored and processed by AI.
- Logic Programming → Programming paradigm using formal logic for problem-solving.
- Hybrid AI → Systems integrating multiple AI paradigms for enhanced capabilities.
- Explainable AI (XAI) → Making AI decisions understandable to humans.
