## Quick Definition
Temporal attention mechanisms allow neural networks to dynamically weigh the importance of different parts of an input sequence over time. This selective focus helps models process long sequences more effectively, capture long-range dependencies, and improve performance in tasks like machine translation and speech recognition by highlighting salient temporal features.

## Key Concepts
- Attention Score → A numerical value indicating the relevance of an input element to the current output.
- Context Vector → A weighted sum of input features, representing the most pertinent information for a given step.
- Encoder-Decoder → A neural architecture where an encoder processes input and a decoder generates output, often linked by attention.
- Self-Attention → An attention mechanism that relates different positions of a single sequence to compute a representation of the same sequence.
- Multi-Head Attention → Allows the model to jointly attend to information from different representation subspaces.
- Positional Encoding → Injects information about the relative or absolute position of tokens in a sequence.
