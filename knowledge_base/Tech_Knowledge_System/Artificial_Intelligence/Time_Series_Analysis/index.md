## Quick Definition
Time Series Analysis (TSA) is a specialized field within data science and AI that focuses on analyzing data points indexed in time order. It aims to extract meaningful statistics and characteristics from sequential data to forecast future values, detect anomalies, and understand underlying temporal dynamics.

## Key Concepts
- Stationarity → data properties remain constant over time
- Autocorrelation → correlation of a series with its past values
- Trend → long-term directional movement in data
- Seasonality → recurring patterns at fixed intervals
- Forecasting → predicting future values based on historical data
- Anomaly Detection → identifying unusual data points or patterns
- Lag Features → past values used as predictors
- Rolling Statistics → summary statistics over a moving window
