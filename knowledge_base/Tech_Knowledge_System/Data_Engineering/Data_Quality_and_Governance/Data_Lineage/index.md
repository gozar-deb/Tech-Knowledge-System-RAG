## Quick Definition
Data lineage is the process of tracking the complete lifecycle of data, from its origin to its current state, including all transformations and movements. It provides a clear audit trail, enabling understanding of data's journey and ensuring its trustworthiness and compliance.

## Key Concepts
- Data Provenance → Understanding the source and history of data.
- Data Flow Mapping → Visualizing the path data takes through systems.
- Metadata Capture → Collecting descriptive information about data assets.
- Transformation Tracking → Recording how data changes at each processing step.
- Impact Analysis → Evaluating the effects of data changes on dependent systems.
- Audit Trail → Maintaining a verifiable record of data's history for compliance.
