## Quick Definition
Metrics, Prometheus, and Grafana constitute a powerful open-source stack for comprehensive system monitoring and observability. Prometheus collects and stores time-series data, while Grafana provides advanced visualization and dashboarding capabilities, enabling real-time insights into infrastructure and application performance.

## Key Concepts
- Prometheus → A pull-based monitoring system for time-series data with a powerful query language.
- Grafana → A visualization platform for creating interactive dashboards from various data sources.
- Time-Series Database (TSDB) → A database optimized for storing and retrieving data points indexed by time.
- Exporters → Agents that expose metrics from services in a Prometheus-compatible format.
- PromQL → Prometheus Query Language, used for querying and aggregating metrics.
- Alertmanager → Component that handles and routes alerts generated by Prometheus.
