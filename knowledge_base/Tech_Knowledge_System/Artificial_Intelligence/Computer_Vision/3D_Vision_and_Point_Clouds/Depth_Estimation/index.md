## Quick Definition
Depth estimation is a computer vision technique that predicts the distance of objects from a camera, generating a depth map. This process is crucial for enabling machines to understand the 3D geometry and spatial relationships within a scene, converting 2D image data into actionable 3D information.

## Key Concepts
- Monocular Depth Estimation → Predicting depth from a single 2D image.
- Stereo Vision → Calculating depth using disparity from multiple camera views.
- Depth Map → A visual representation where pixel intensity indicates distance.
- Disparity → Positional difference of corresponding points in stereo images.
- Time-of-Flight (ToF) Sensors → Active sensors measuring light return time for direct depth.
- Point Cloud → A collection of 3D data points representing object surfaces.
