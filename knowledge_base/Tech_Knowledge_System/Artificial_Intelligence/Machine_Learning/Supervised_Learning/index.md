## Quick Definition
Supervised learning is a core machine learning approach where algorithms learn from labeled datasets to make predictions. It involves training a model on input-output pairs to infer a mapping function, primarily used for classification and regression tasks.

## Key Concepts
- Labeled Data → Data with known output values used for training.
- Classification → Predicting a categorical output label.
- Regression → Predicting a continuous numerical output value.
- Training Set → The portion of data used to train the model.
- Test Set → The portion of data used to evaluate the trained model's performance.
- Validation Set → Data used for hyperparameter tuning and model selection.
- Feature Scaling → Normalizing or standardizing input features.
- Hyperparameters → Parameters set before training, controlling the learning process.
