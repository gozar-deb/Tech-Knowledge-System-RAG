## Quick Definition
Cloud Security is the discipline of protecting cloud-based assets, applications, and infrastructure from threats and vulnerabilities. It involves implementing policies, controls, and technologies to ensure data privacy, compliance, and operational resilience within dynamic cloud environments.

## Key Concepts
- Shared Responsibility Model → delineates security duties between cloud provider and customer
- IAM (Identity and Access Management) → manages digital identities and access permissions to cloud resources
- Data Encryption → secures data at rest, in transit, and in use within cloud platforms
- CSPM (Cloud Security Posture Management) → continuously monitors cloud configurations for misconfigurations and compliance deviations
- CWPP (Cloud Workload Protection Platforms) → protects workloads (VMs, containers, serverless) across multi-cloud environments
- DevSecOps → integrates security practices into every phase of the cloud development lifecycle
- Zero Trust Architecture → assumes no implicit trust and verifies every access request
