## Quick Definition
API Design is the strategic process of creating interfaces that allow different software systems to communicate effectively. It focuses on defining clear contracts for data exchange and operations, ensuring usability, consistency, and scalability for developers and integrated applications.

## Key Concepts
- REST → An architectural style for building web services using HTTP methods and resource-based URLs.
- GraphQL → A query language for APIs that allows clients to request exactly the data they need.
- Idempotency → An operation that can be applied multiple times without changing the result beyond the initial application.
- Versioning → Managing changes to an API over time to maintain backward compatibility for clients.
- API Gateway → A management layer that acts as a single entry point for multiple APIs or microservices.
- OpenAPI Specification → A standard, language-agnostic interface description for RESTful APIs.
