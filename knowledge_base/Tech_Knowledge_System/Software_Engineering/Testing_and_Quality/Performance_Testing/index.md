## Quick Definition
Performance testing assesses a system's speed, scalability, and stability under various workloads. It identifies bottlenecks and ensures applications meet defined performance benchmarks, crucial for user experience and system reliability.

## Key Concepts
- Load Testing → Simulating expected user traffic to evaluate system behavior.
- Stress Testing → Pushing system beyond normal limits to find breaking points and stability.
- Scalability Testing → Measuring system's capacity to handle increased user or data volume.
- Response Time → The duration from user request to system's first response.
- Throughput → The rate at which a system successfully processes transactions or requests.
- Bottleneck Analysis → Identifying specific components or processes limiting overall system performance.
