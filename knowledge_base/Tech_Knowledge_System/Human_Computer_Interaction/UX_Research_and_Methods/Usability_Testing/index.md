## Quick Definition
Usability testing is a method for evaluating a product by testing it with representative users to identify design flaws and areas for improvement. It involves observing users as they complete tasks to understand their interactions and pain points, ensuring the product is intuitive and effective.

## Key Concepts
- User Observation → Directly watching users interact with a product.
- Task Completion → Users perform specific actions to assess product functionality.
- Pain Points → Difficulties or frustrations users experience.
- Design Flaws → Elements hindering usability or user experience.
- Representative Users → Participants reflecting the target audience.
- Moderated Testing → Facilitator guides users and asks questions.
- Unmoderated Testing → Users complete tasks independently, often remotely.
- Qualitative Data → Non-numerical insights from observations and feedback.
- Quantitative Data → Measurable data like task completion rates and errors.
- Iterative Testing → Repeated testing throughout the development lifecycle.
