## Quick Definition
Question Answering (QA) and Dialogue systems are subfields of Natural Language Processing focused on enabling machines to understand and respond to human language queries. QA extracts precise answers from text, while dialogue systems manage multi-turn conversations to achieve specific user objectives, forming the backbone of conversational AI.

## Key Concepts
- Machine Comprehension → AI's ability to understand text content and context.
- Information Retrieval → Locating relevant data or documents from a corpus.
- Semantic Parsing → Converting natural language into structured, executable forms.
- Intent Recognition → Identifying the user's goal or purpose in an utterance.
- Slot Filling → Extracting specific entities (e.g., dates, locations) from user input.
- Response Generation → Creating natural language replies, either retrieval-based or generative.
- Context Tracking → Maintaining conversational history for coherent interactions.
- Coreference Resolution → Linking expressions that refer to the same entity.
- Knowledge Graphs → Structured data used for factual QA and reasoning.
- Conversational AI → Broad field encompassing systems for human-computer dialogue.
