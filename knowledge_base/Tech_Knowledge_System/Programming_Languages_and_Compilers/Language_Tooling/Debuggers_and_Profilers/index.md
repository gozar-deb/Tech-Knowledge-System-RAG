## Quick Definition
Debuggers are essential tools for identifying and resolving software defects by allowing developers to inspect program state and control execution flow. Profilers analyze runtime characteristics like CPU usage, memory consumption, and I/O operations to optimize performance and resource efficiency.

## Key Concepts
- Breakpoint → A designated point in code where execution pauses for inspection.
- Stepping → Executing code line by line (step over, step into, step out).
- Call Stack → Ordered list of active functions or subroutines during program execution.
- Memory Profiling → Analyzing memory allocation and deallocation to detect leaks or inefficiencies.
- CPU Profiling → Measuring CPU time spent in different code sections to pinpoint performance bottlenecks.
- Instrumentation → Modifying code to insert monitoring points for data collection.
