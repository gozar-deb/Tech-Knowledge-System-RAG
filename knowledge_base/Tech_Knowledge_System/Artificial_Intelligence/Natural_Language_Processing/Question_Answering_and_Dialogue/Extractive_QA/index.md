## Quick Definition
Extractive Question Answering (QA) is an NLP task focused on finding and extracting a precise segment of text from a given document as the answer to a question. It leverages machine reading comprehension to identify the most relevant span, ensuring answers are directly supported by the source material without generating new content.

## Key Concepts
- Machine Reading Comprehension (MRC) → machine's ability to understand text and answer questions.
- Span Prediction → identifying the exact start and end points of an answer within a text.
- Contextual Embeddings → vector representations capturing word meaning based on surrounding words.
- Fine-tuning → adapting pre-trained models to specific QA datasets for improved performance.
- Attention Mechanism → neural network component allowing models to focus on critical input parts.
- F1-score → evaluation metric measuring the accuracy of extracted answer spans.
