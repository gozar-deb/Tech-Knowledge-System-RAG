## Quick Definition
Rendering fundamentals are the foundational principles and algorithms for generating 2D images from 3D scene data. They encompass techniques like rasterization and ray tracing, along with shading, lighting, and texture application, crucial for all computer graphics applications.

## Key Concepts
- Rasterization → Converts 3D geometric primitives into 2D pixels on a screen.
- Ray Tracing → Simulates light rays to produce highly realistic images by tracking light paths.
- Shading → Determines the final color of a pixel based on light interaction with a surface.
- Lighting Models → Mathematical descriptions of how light sources illuminate objects.
- Texture Mapping → Applies 2D images to 3D models to add surface detail and color.
- Z-Buffer → A depth buffer used to manage object visibility and prevent rendering errors.
- Global Illumination → Techniques that simulate indirect lighting, reflections, and refractions.
- Physically Based Rendering (PBR) → A rendering paradigm based on real-world physics for accurate light simulation.
