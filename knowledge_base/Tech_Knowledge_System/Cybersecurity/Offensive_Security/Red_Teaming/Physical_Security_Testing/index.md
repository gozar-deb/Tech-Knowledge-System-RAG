## Quick Definition
Physical Security Testing is a specialized discipline within offensive security that assesses the resilience of an organization's physical controls against unauthorized access. It involves simulating real-world intrusion attempts to uncover vulnerabilities in physical infrastructure, human processes, and security systems, often as part of a red team operation.

## Key Concepts
- Physical Reconnaissance → Gathering intelligence on physical layouts and security measures.
- Access Control Bypass → Circumventing physical barriers like locks, gates, and biometric systems.
- Social Engineering (Physical) → Manipulating individuals to gain physical access or information.
- Surveillance Evasion → Techniques to avoid detection by cameras and motion sensors.
- Covert Entry → Gaining unauthorized access without leaving obvious signs of forced entry.
- Insider Threat Simulation → Evaluating vulnerabilities related to trusted personnel.
