## Quick Definition
Stochastic processes are mathematical constructs that model systems evolving randomly over time. They are sequences of random variables, where each variable represents the system's state at a particular time point, enabling the analysis of unpredictable phenomena.

## Key Concepts
- Markov Chain → Future state depends only on the current state.
- Poisson Process → Models event counts over time at a constant rate.
- Brownian Motion → Continuous random movement, often for financial modeling.
- Stationarity → Statistical properties remain constant over time.
- Ergodicity → Time averages equal ensemble averages.
- Martingale → Expected future value equals current value, given past.
- Random Walk → Path of successive random steps.
- Stochastic Differential Equation (SDE) → Differential equation with random noise terms.
