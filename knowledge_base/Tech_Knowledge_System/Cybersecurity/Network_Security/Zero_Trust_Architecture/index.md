## Quick Definition
Zero Trust Architecture (ZTA) is a security framework that operates on the principle of "never trust, always verify," requiring strict authentication and authorization for every access request. It assumes no implicit trust, even for internal users and devices, thereby minimizing the attack surface and containing potential breaches.

## Key Concepts
- Microsegmentation → Isolating network resources into small, secure zones.
- Least Privilege → Granting minimal access rights required for a task.
- MFA → Verifying user identity through multiple authentication factors.
- Continuous Monitoring → Real-time analysis of activity for security threats.
- Device Posture → Assessing device health and compliance before granting access.
- Adaptive Policies → Dynamically adjusting access based on context and risk.
