## Quick Definition
3D Vision and Point Clouds is a subfield of computer vision focused on acquiring, processing, and interpreting three-dimensional spatial data. It enables machines to perceive and understand the geometry of their surroundings, crucial for tasks like navigation, object manipulation, and environmental modeling.

## Key Concepts
- Point Cloud → A collection of 3D data points representing the surface of an object or scene.
- 3D Reconstruction → Generating a 3D model from 2D images or sensor data.
- LiDAR → A remote sensing method using pulsed laser light to measure distances and create 3D representations.
- Photogrammetry → Creating 3D models and measurements from photographic images.
- Geometric Deep Learning → Applying deep learning directly to 3D geometric data structures.
- SLAM (Simultaneous Localization and Mapping) → Building a map of an unknown environment while simultaneously tracking the agent's location within it.
