## Quick Definition
Mobile and IoT Federated Learning extends federated learning to resource-constrained edge devices, enabling collaborative model training without centralizing sensitive data. It addresses privacy, bandwidth, and latency challenges by performing computation locally and exchanging only aggregated model updates.

## Key Concepts
- On-Device Training → Models are trained directly on local device data.
- Resource Constraints → Limited compute, memory, and battery on mobile/IoT devices.
- Data Heterogeneity → Diverse data distributions across different devices.
- Communication Efficiency → Minimizing network traffic by sending small model updates.
- Privacy Preservation → Raw data never leaves the local device.
- Edge Intelligence → AI processing occurs close to the data source, reducing latency.
