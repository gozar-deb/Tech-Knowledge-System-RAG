## Quick Definition
Conversational Recommender Systems (CRSs) are interactive AI systems that guide users to relevant items through natural language dialogue. They leverage multi-turn conversations to understand evolving user preferences and provide personalized suggestions, often powered by large language models (LLMs) for enhanced understanding and generation.

## Key Concepts
- Multi-turn Dialogue → Sequential interactions to refine user preferences.
- Preference Elicitation → Techniques for extracting user tastes and intentions.
- Natural Language Understanding (NLU) → Interpreting user input in natural language.
- Natural Language Generation (NLG) → Creating human-like system responses.
- User Modeling → Dynamically building and updating user preference profiles.
- Contextual Awareness → Using dialogue history for relevant recommendations.
- Explainable Recommendations → Providing reasons for suggested items.
- LLM Integration → Using large language models for conversational intelligence.
