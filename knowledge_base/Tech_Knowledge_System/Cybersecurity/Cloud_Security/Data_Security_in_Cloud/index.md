## Quick Definition
Data Security in Cloud involves implementing controls and measures to protect data across its lifecycle within cloud environments. It ensures confidentiality, integrity, and availability, addressing unique cloud-specific threats and regulatory compliance.

## Key Concepts
- Encryption → Protecting data using cryptographic methods at rest and in transit.
- Access Control → Restricting data access based on identity and permissions.
- Data Loss Prevention (DLP) → Preventing sensitive data from unauthorized egress.
- Data Residency → Complying with legal requirements for data storage location.
- Data Governance → Managing data lifecycle, quality, and security policies.
- Cloud Security Posture Management (CSPM) → Continuously monitoring cloud configurations for security risks.
