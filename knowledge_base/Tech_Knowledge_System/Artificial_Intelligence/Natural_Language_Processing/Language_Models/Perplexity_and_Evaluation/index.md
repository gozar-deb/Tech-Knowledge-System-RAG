## Quick Definition
Perplexity measures a language model's predictive uncertainty on text, with lower values indicating better performance. Evaluation encompasses a range of metrics and methodologies to comprehensively assess a language model's quality, utility, and performance across diverse NLP tasks and real-world applications.

## Key Concepts
- Perplexity → A measure of how well a language model predicts a text sample.
- Cross-Entropy → A metric closely related to perplexity, quantifying prediction error.
- BLEU → An n-gram overlap metric for machine translation quality assessment.
- ROUGE → A recall-oriented metric suite for summarization and translation evaluation.
- Human Evaluation → Subjective assessment by humans for nuanced quality aspects.
- Intrinsic Evaluation → Assessing model performance on isolated sub-tasks, often using statistical metrics.
- Extrinsic Evaluation → Evaluating model utility within a larger application context.
- LLM-based Evaluation → Using one LLM to assess the outputs or performance of another LLM.
