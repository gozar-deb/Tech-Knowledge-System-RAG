## Quick Definition
Information Theory is a mathematical discipline that quantifies information, its storage, and its transmission. It establishes theoretical limits for data compression and reliable communication over noisy channels, forming the bedrock of digital communication and data processing.

## Key Concepts
- Entropy → Measures the uncertainty or information content of a random variable.
- Mutual Information → Quantifies the shared information between two random variables.
- Channel Capacity → The maximum rate for error-free data transmission over a channel.
- Source Coding → Algorithms for efficient data compression, reducing redundancy.
- Channel Coding → Methods for adding redundancy to detect and correct transmission errors.
- Noisy Channel Coding Theorem → Proves reliable communication is possible below channel capacity.
