## Quick Definition
Named Entity Recognition (NER) is a core natural language processing task that identifies and classifies key information (entities) in text into predefined categories. It helps structure unstructured data by recognizing elements like person names, organizations, locations, and dates, enabling deeper textual understanding.

## Key Concepts
- Named Entity → A real-world object identified in text.
- Entity Type → The category assigned to a named entity (e.g., Person, Location).
- Sequence Labeling → A common approach where each word in a sentence is tagged.
- IOB Tagging → A scheme to mark the beginning, inside, or outside of an entity.
- Gazetteer → A dictionary of known entities used for lookup.
- Pre-trained Language Models → Large models fine-tuned for NER tasks (e.g., BERT).
