## Quick Definition
Anomaly detection is the process of identifying data points, events, or observations that deviate significantly from the majority of the data, indicating unusual or suspicious behavior. It is a critical task in various domains for uncovering rare but important occurrences like fraud, system faults, or security threats.

## Key Concepts
- Outlier → A data point that is distant from other observations.
- Novelty Detection → Identifying new, previously unseen patterns.
- One-Class SVM → A model trained on normal data to detect deviations.
- Isolation Forest → An ensemble method for isolating anomalies.
- Reconstruction Error → Used in autoencoders to flag unusual inputs.
- Local Outlier Factor (LOF) → Measures local density deviation of a data point.
