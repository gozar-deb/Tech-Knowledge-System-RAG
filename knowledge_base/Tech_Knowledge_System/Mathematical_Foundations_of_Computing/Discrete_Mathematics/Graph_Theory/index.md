## Quick Definition
Graph theory is a mathematical discipline studying graphs, which are structures representing relationships between objects. It uses vertices and edges to model networks, dependencies, and connections, providing tools for analyzing complex systems in various fields.

## Key Concepts
- Graph → A collection of vertices and edges representing connections.
- Vertex (Node) → An individual entity or point in a graph.
- Edge (Link) → A connection between two vertices.
- Path → A sequence of connected vertices in a graph.
- Cycle → A path that begins and ends at the same vertex.
- Tree → A connected graph with no cycles.
- Adjacency Matrix → A square matrix indicating direct connections between vertices.
- Shortest Path Algorithm → Finds the path with the minimum weight or fewest edges between two vertices.
