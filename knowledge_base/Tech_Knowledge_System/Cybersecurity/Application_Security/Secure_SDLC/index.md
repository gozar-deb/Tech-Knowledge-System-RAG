## Quick Definition
The Secure Software Development Lifecycle (SSDLC) is a structured process that integrates security activities and considerations into every phase of software development. Its primary goal is to build secure applications by proactively identifying, mitigating, and preventing security vulnerabilities from the initial design stages through deployment and ongoing maintenance.

## Key Concepts
- Threat Modeling → Identifying potential security threats and vulnerabilities early in the design phase.
- Security Requirements → Specifying security controls and features as part of functional requirements.
- Secure Coding → Writing code that is resistant to common vulnerabilities and follows security best practices.
- SAST (Static Application Security Testing) → Analyzing source code for security flaws without execution.
- DAST (Dynamic Application Security Testing) → Testing a running application for vulnerabilities from an attacker's perspective.
- Penetration Testing → Simulating real-world attacks to find exploitable weaknesses in an application.
- Security Gates → Mandatory checkpoints to ensure security criteria are met before advancing SDLC phases.
- DevSecOps → Integrating security practices seamlessly into the DevOps pipeline for continuous security.
