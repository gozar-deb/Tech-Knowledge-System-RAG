## Quick Definition
Memory systems are the digital storage components within a computer architecture, designed to hold data and instructions for the CPU. They are organized in a hierarchy to optimize access speed and cost, playing a crucial role in overall system performance and responsiveness.

## Key Concepts
- RAM → Volatile memory for active data and programs.
- ROM → Non-volatile memory for firmware and boot instructions.
- Cache Memory → Fast, small memory for frequently accessed data.
- Virtual Memory → Uses disk space to extend physical RAM capacity.
- Memory Hierarchy → Tiered structure balancing speed, cost, and capacity.
- Memory Controller → Manages data flow between CPU and main memory.
- DRAM → Main memory type requiring periodic refresh.
- SRAM → Faster, cache memory type not requiring refresh.
- Memory Addressing → Unique identification of memory locations.
- Memory Protection → Prevents unauthorized memory access.
- Memory Bandwidth → Rate at which data can be read from or stored into memory.
- Memory Latency → Delay between a memory request and data availability.
