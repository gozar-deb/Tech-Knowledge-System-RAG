## Quick Definition
Network security is a critical subset of cybersecurity focused on protecting the integrity, confidentiality, and availability of computer networks and data. It employs various technologies and policies to prevent unauthorized access, misuse, and disruption of network resources, ensuring secure communication and data transfer.

## Key Concepts
- Confidentiality → Ensuring data is accessible only to authorized entities.
- Integrity → Maintaining the accuracy and completeness of data, preventing unauthorized alteration.
- Availability → Guaranteeing reliable and timely access to network resources for authorized users.
- Authentication → Verifying the identity of users or devices.
- Authorization → Defining the permissions and access rights for authenticated entities.
- Non-repudiation → Providing undeniable proof of an action\'s origin and integrity.

## Tools

| Tool | Type | Purpose |
|------|------|---------|
| Firewalls (e.g., Palo Alto, Cisco ASA) | Hardware/Software | Control incoming and outgoing network traffic based on security rules. |
| Intrusion Detection/Prevention Systems (IDS/IPS) | Software/Appliance | Monitor network traffic for malicious activity and take action to prevent threats. |
| Virtual Private Networks (VPNs) | Software/Protocol | Create secure, encrypted connections over a less secure network, like the internet. |
| Security Information and Event Management (SIEM) | Software | Collect and analyze security alerts and logs from various sources to identify threats. |
| Network Access Control (NAC) | Software | Restrict the availability of network resources to endpoints that comply with a defined security policy. |
| Data Loss Prevention (DLP) | Software | Detect and prevent sensitive data from leaving the network. |
