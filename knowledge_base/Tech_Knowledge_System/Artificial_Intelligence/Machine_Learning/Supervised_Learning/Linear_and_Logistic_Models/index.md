## Quick Definition
Linear and Logistic Models are foundational supervised learning algorithms. Linear Regression predicts continuous outcomes by fitting a linear equation, while Logistic Regression predicts probabilities for categorical outcomes using a sigmoid function, making it suitable for classification tasks.

## Key Concepts
- Linear Regression → models linear relationship for continuous predictions
- Logistic Regression → models probabilities for classification using a sigmoid function
- Supervised Learning → learning from labeled data to make predictions
- Cost Function → quantifies model prediction error
- Gradient Descent → optimization algorithm to minimize cost function
- Sigmoid Function → transforms linear output to probabilities between 0 and 1
- Overfitting → model learns training data too well, performs poorly on new data
- Regularization → techniques to prevent overfitting by penalizing complexity
