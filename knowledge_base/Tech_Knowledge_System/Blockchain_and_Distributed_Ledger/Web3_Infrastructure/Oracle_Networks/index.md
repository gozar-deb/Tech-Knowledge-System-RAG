## Quick Definition
Oracle networks are essential Web3 infrastructure that securely and reliably connect blockchain smart contracts with external, real-world data and off-chain systems. They overcome the inherent limitation of blockchains being isolated from external information, enabling smart contracts to react to events and data beyond their native environment.

## Key Concepts
- Oracle Problem → The challenge of securely feeding off-chain data to on-chain smart contracts.
- Decentralized Oracle Networks (DONs) → Networks of independent nodes providing data to enhance security and reliability.
- Data Feeds → Continuous streams of external data, such as price information, delivered by oracles.
- Off-chain Data → Information existing outside the blockchain, accessed and validated by oracles.
- On-chain Data → Data stored directly on the blockchain, often updated by oracle networks.
- Data Aggregation → Combining data from multiple sources to ensure accuracy and resilience.
