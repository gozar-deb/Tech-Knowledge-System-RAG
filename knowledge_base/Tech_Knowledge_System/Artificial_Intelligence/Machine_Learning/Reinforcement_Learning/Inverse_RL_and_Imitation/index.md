## Quick Definition
Inverse Reinforcement Learning (IRL) deduces the reward function from observed expert behavior. Imitation Learning (IL) directly learns a policy to replicate expert actions. Both paradigms enable agents to acquire skills from demonstrations, bypassing explicit reward specification.

## Key Concepts
- Inverse Reinforcement Learning (IRL) → Inferring reward functions from expert demonstrations.
- Imitation Learning (IL) → Directly learning a policy to mimic expert behavior.
- Behavioral Cloning (BC) → Supervised learning approach for imitation, mapping states to actions.
- Apprenticeship Learning → Iterative IRL method where an agent learns to match or exceed expert performance.
- Expert Demonstrations → Data provided by a skilled agent, crucial for training both IRL and IL models.
- Reward Function → The objective function an agent aims to maximize, inferred in IRL.
- Policy → A mapping from states to actions, learned in IL.
- Generalization → The ability of a learned model to perform well on unseen data.
