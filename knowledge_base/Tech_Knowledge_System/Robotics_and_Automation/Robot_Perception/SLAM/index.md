## Quick Definition
Simultaneous Localization and Mapping (SLAM) is a core robotics problem where an agent builds a map of an unknown environment while simultaneously determining its own position within that map. It is essential for autonomous navigation and environmental understanding in dynamic settings.

## Key Concepts
- Localization → Determining an agent's position within a map.
- Mapping → Creating a representation of the environment.
- Sensor Fusion → Combining data from various sensors for improved accuracy.
- Odometry → Estimating motion from internal sensors or visual cues.
- Loop Closure → Recognizing revisited locations to correct accumulated errors.
- State Estimation → Probabilistic methods for estimating pose and map features.
