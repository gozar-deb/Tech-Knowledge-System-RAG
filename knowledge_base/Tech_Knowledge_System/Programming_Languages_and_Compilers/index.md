## Quick Definition
Programming languages provide formal notations for instructing computers, while compilers translate these high-level instructions into machine-executable code. This field encompasses the design, implementation, and optimization of these critical software components, forming the bedrock of all computational systems.

## Key Concepts
- **Syntax** → The set of rules defining the valid structure of a programming language.
- **Semantics** → The meaning associated with valid programming language constructs.
- **Lexical Analysis** → The process of breaking source code into a stream of tokens.
- **Parsing** → The process of analyzing the syntactic structure of a program, often creating an Abstract Syntax Tree (AST).
- **Intermediate Representation (IR)** → An abstract form of code used by compilers for optimization before generating machine code.
- **Code Generation** → The final phase where optimized IR is translated into target machine code.
- **Optimization** → Techniques applied to IR or machine code to improve performance, size, or power consumption.
- **Runtime Environment** → The system where a compiled or interpreted program executes, including memory management and garbage collection.

## Tools

| Tool | Type | Purpose |
|------|------|---------|
| GCC | Compiler | A widely used collection of compilers for various languages like C, C++, Fortran. |
| LLVM | Compiler Infrastructure | A modular and reusable compiler and toolchain technology, used in many modern compilers. |
| ANTLR | Parser Generator | A powerful tool for constructing parsers, interpreters, compilers, and translators from grammar descriptions. |
| JVM | Runtime Environment | A virtual machine that enables a computer to run Java programs as well as programs written in other languages that are compiled to Java bytecode. |
| Roslyn | Compiler as a Service | Microsoft's open-source .NET compiler platform, providing rich code analysis APIs. |
| Flex/Bison | Lexer/Parser Generators | Classic Unix tools for generating lexical analyzers (Flex) and parsers (Bison). |
