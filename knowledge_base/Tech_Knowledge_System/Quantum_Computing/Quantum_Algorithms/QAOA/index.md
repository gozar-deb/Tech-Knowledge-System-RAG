## Quick Definition
QAOA is a hybrid quantum-classical algorithm designed to find approximate solutions to combinatorial optimization problems. It uses a parameterized quantum circuit optimized by a classical computer to iteratively improve solutions, making it suitable for Near-Term Intermediate-Scale Quantum (NISQ) devices.

## Key Concepts
- Variational Quantum Algorithms → Hybrid algorithms using classical optimization for quantum circuits.
- Combinatorial Optimization → Finding optimal solutions from a finite set of discrete choices.
- Adiabatic Quantum Computation → A quantum paradigm for solving optimization problems by evolving a system.
- Parameterized Quantum Circuits (PQC) → Quantum circuits with adjustable gate parameters for optimization.
- Classical Optimizer → An algorithm (e.g., COBYLA) used to update PQC parameters on a classical computer.
- Objective Function → A mathematical expression that QAOA aims to minimize or maximize.
- Max-Cut Problem → A classic graph theory problem often used as a benchmark for QAOA.
