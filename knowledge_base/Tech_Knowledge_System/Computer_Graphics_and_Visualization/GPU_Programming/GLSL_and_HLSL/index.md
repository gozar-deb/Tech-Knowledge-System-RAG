## Quick Definition
GLSL and HLSL are high-level shading languages used to program Graphics Processing Units (GPUs). They allow developers to define how 3D objects are rendered, controlling aspects like vertex transformation, lighting, and pixel coloring for real-time graphics.

## Key Concepts
- Shaders → Small programs run on the GPU for graphics processing.
- Vertex Shader → Transforms 3D vertex positions and attributes.
- Fragment Shader → Determines the final color of each pixel.
- Graphics Pipeline → The sequence of stages a 3D scene undergoes to become a 2D image.
- Compute Shader → General-purpose GPU program for non-graphics tasks.
- Shader Model → Defines the capabilities and instruction set of a shader language version.
