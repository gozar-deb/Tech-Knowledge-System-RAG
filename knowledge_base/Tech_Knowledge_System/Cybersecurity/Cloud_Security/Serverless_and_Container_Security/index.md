## Quick Definition
Serverless and container security focuses on safeguarding dynamic, ephemeral cloud workloads like FaaS functions and containerized applications. It involves securing the build, deploy, and runtime phases against vulnerabilities, misconfigurations, and unauthorized access in cloud-native environments.

## Key Concepts
- Image Scanning → Analyzing container images for security flaws before deployment.
- Runtime Protection → Monitoring and securing serverless functions and containers during execution.
- Least Privilege → Granting minimal necessary permissions to cloud resources and identities.
- Supply Chain Security → Protecting the entire software delivery pipeline from code to deployment.
- Secrets Management → Securely handling sensitive credentials and configuration data.
- Network Segmentation → Isolating workloads to limit potential attack impact.
