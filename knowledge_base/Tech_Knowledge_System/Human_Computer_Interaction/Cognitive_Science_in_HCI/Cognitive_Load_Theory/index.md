## Quick Definition
Cognitive Load Theory (CLT) explains how the limited capacity of working memory affects learning and performance. It categorizes cognitive load into intrinsic, extraneous, and germane, providing a framework for designing effective instructional materials and user interfaces that optimize mental effort.

## Key Concepts
- Working Memory → A temporary storage and processing system with limited capacity.
- Intrinsic Load → The inherent difficulty of the subject matter itself.
- Extraneous Load → Unnecessary mental effort caused by poor design or presentation.
- Germane Load → Mental effort invested in understanding and building knowledge structures (schemas).
- Schema Theory → Organized units of knowledge stored in long-term memory.
- Expertise Reversal Effect → Instructional strategies can have different effects on novices vs. experts.
