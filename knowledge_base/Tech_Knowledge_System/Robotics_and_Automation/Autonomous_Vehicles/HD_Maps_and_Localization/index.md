## Quick Definition
HD Maps and Localization are fundamental to autonomous driving, enabling vehicles to precisely determine their location and orientation within a highly detailed digital map. This involves correlating real-time sensor data with pre-built, centimeter-accurate maps of the environment.

## Key Concepts
- HD Maps → Highly detailed digital maps with static environmental features.
- Localization → Determining an autonomous vehicle\'s exact position and orientation.
- Sensor Fusion → Combining data from multiple sensors for robust localization.
- Global Localization → Initial positioning within a broad map area.
- Local Localization → Continuous tracking of position relative to the immediate environment.
- Map Matching → Aligning sensor observations with map features.
- Lane-Level Accuracy → Positioning within a specific lane.
