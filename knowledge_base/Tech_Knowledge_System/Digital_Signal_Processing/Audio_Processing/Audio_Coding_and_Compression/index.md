## Quick Definition
Audio coding and compression are techniques used to reduce the data size of digital audio while preserving perceived quality. This is achieved by removing redundant or perceptually irrelevant information, enabling more efficient storage and transmission of sound.

## Key Concepts
- Perceptual Coding → Exploits human hearing limitations to remove inaudible data.
- Lossy Compression → Irreversibly discards data for smaller file sizes (e.g., MP3).
- Lossless Compression → Retains all original data, allowing perfect reconstruction (e.g., FLAC).
- Codec → An algorithm for encoding and decoding digital audio.
- Bit Rate → The amount of data per second, influencing audio quality and file size.
- Psychoacoustics → The study of sound perception, vital for lossy codec design.
