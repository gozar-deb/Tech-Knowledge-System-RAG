## Quick Definition
Virtual memory is an OS technique that gives processes an illusion of a large, contiguous memory space, abstracting physical RAM. Paging is a core mechanism of virtual memory, dividing both logical and physical memory into fixed-size blocks (pages and frames) to enable efficient, protected memory management and allow programs to exceed physical memory limits.

## Key Concepts
- Virtual Address → Address generated by the CPU, requiring translation.
- Physical Address → Actual address in main memory.
- Page Table → OS data structure mapping virtual to physical addresses.
- Translation Lookaside Buffer (TLB) → Hardware cache for fast address translation.
- Page Fault → Interrupt when a requested page is not in physical memory.
- Swap Space → Disk area used to store inactive memory pages.
- Demand Paging → Loading pages into RAM only when accessed.
- Memory Protection → Preventing unauthorized memory access between processes.
