## Quick Definition
Cloud computing delivers on-demand computing services over the internet, offering flexibility and scalability. Distributed computing involves multiple interconnected computers working together to solve a problem, forming the foundational architecture for many cloud services, enabling high availability and fault tolerance.

## Key Concepts
- Cloud Computing → On-demand delivery of IT resources over the Internet.
- Distributed Systems → Multiple autonomous computers working as a single, coherent system.
- Scalability → Ability to handle increased load by adding resources.
- Elasticity → Automatic adjustment of resources to match demand.
- Microservices → Small, independent services communicating via APIs.
- Containerization → Packaging applications and dependencies into portable units.
- Serverless → Cloud execution model where infrastructure management is abstracted.
- Fault Tolerance → System's ability to continue functioning despite component failures.
