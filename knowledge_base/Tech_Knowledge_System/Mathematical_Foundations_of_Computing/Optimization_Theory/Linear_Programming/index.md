## Quick Definition
Linear Programming is a mathematical technique for optimizing a linear objective function, such as maximizing profit or minimizing cost, subject to a set of linear equality and inequality constraints. It is a cornerstone of operations research, providing systematic methods for resource allocation and decision-making in complex systems.

## Key Concepts
- Objective Function → The mathematical expression to be optimized (maximized or minimized).
- Constraints → Linear equations or inequalities that limit the possible values of decision variables.
- Decision Variables → The unknown quantities in an LP problem that need to be determined.
- Feasible Region → The set of all points that satisfy all the constraints of the problem.
- Simplex Method → An iterative algorithm for finding the optimal solution to linear programming problems.
- Duality Theory → The relationship between a primal LP problem and its corresponding dual problem.
- Basic Solution → A solution obtained by setting non-basic variables to zero and solving for basic variables.
- Convexity → The feasible region of an LP is always a convex set, which guarantees local optima are global optima.
