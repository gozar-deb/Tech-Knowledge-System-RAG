## Quick Definition
CPU Architecture defines the fundamental design and operational model of a Central Processing Unit, encompassing its Instruction Set Architecture (ISA) and microarchitectural implementation. It dictates how instructions are processed, data is managed, and overall system performance is achieved.

## Key Concepts
- Instruction Set Architecture (ISA) → The set of instructions a CPU can execute.
- Microarchitecture → The specific internal design and implementation of a CPU.
- Pipelining → Overlapping instruction execution stages for increased throughput.
- Cache Hierarchy → Multi-level fast memory to reduce average memory access time.
- Multicore Processing → Multiple independent processing units on a single chip.
- Register File → Fast storage within the CPU for active data and instructions.
- Branch Prediction → Guessing future program flow to avoid pipeline stalls.
- Out-of-Order Execution → Executing instructions non-sequentially for efficiency.
