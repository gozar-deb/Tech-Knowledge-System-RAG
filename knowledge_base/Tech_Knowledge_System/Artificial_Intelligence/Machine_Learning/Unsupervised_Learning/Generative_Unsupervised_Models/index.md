## Quick Definition
Generative unsupervised models learn the underlying probability distribution of unlabeled data to create new, realistic samples. They identify patterns and structures within data without explicit guidance, enabling tasks like data synthesis and anomaly detection.

## Key Concepts
- Latent Space → A compressed, meaningful representation of data features.
- Probability Density Estimation → Modeling the likelihood of data points within a distribution.
- Mode Collapse → A failure where models generate limited data diversity.
- Normalizing Flows → Invertible transformations for complex probability distributions.
- Variational Autoencoders (VAEs) → Models that learn data encoding and decoding for generation.
- Generative Adversarial Networks (GANs) → Two-network systems (generator, discriminator) that learn to create realistic data through competition.
