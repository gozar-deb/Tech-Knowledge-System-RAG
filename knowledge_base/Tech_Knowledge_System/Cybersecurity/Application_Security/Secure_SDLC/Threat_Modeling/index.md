## Quick Definition
Threat modeling is a systematic process to identify, categorize, and prioritize potential security threats and vulnerabilities in a system or application design. It helps developers and security professionals proactively understand how an attacker might compromise a system and implement appropriate countermeasures early in the development lifecycle.

## Key Concepts
- Data Flow Diagrams (DFDs) → Visual tools to map data movement and trust boundaries.
- STRIDE → A classification model for common threat types (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege).
- DREAD → A risk assessment model for prioritizing threats based on Damage, Reproducibility, Exploitability, Affected Users, and Discoverability.
- Attack Trees → Hierarchical diagrams illustrating potential attack paths against a system.
- Trust Boundaries → Points in a system where data or control flow crosses different trust levels.
- Mitigation Strategies → Specific controls or design changes to reduce identified risks.
