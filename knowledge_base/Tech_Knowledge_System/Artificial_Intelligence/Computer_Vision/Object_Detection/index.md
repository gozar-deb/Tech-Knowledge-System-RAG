## Quick Definition
Object detection is a core computer vision task focused on identifying and precisely locating specific objects within images or video frames. It combines object classification with spatial localization, typically by drawing bounding boxes around detected instances. This capability is vital for machines to interpret and interact with the visual world.

## Key Concepts
- Bounding Box → A rectangle defining an object's position and size.
- Classification → Assigning a label to a detected object.
- Localization → Pinpointing an object's exact coordinates in an image.
- YOLO (You Only Look Once) → A popular real-time object detection algorithm.
- R-CNN (Region-based Convolutional Neural Network) → A family of models using region proposals for detection.
- Non-Maximum Suppression (NMS) → Filters out redundant overlapping detections.
