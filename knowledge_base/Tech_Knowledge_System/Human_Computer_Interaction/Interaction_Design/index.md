## Quick Definition
Interaction Design (IxD) focuses on creating intuitive and engaging user experiences by defining the behavior and structure of interactive systems. It ensures products are usable, accessible, and satisfying, considering how users interact with digital interfaces and services.

## Key Concepts
- Usability → The ease with which users can learn and use a system.
- User Flows → The sequence of steps a user takes to achieve a goal.
- Affordances → Visual cues that suggest how an object can be interacted with.
- Feedback → Responses from a system to a user's action.
- Mental Models → User's expectations of how a system works.
- Prototyping → Creating preliminary versions of a design for testing and iteration.
