## Quick Definition
Generative AI encompasses artificial intelligence systems that create new, original content like text, images, or code, by learning patterns from existing data. These models are designed to produce novel outputs that mimic human creativity and complexity.

## Key Concepts
- Generative Adversarial Networks (GANs) → two neural networks compete to generate realistic data
- Variational Autoencoders (VAEs) → learn latent data representations for new sample generation
- Diffusion Models → generate high-quality samples by reversing a noise-adding process
- Large Language Models (LLMs) → deep learning models generating human-like text from vast datasets
- Prompt Engineering → crafting inputs to guide generative models for desired outputs
- Synthetic Data Generation → creating artificial data mimicking real-world properties for various uses
