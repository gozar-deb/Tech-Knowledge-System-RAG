## Quick Definition
RSA and ECC are asymmetric cryptographic algorithms that use public/private key pairs for secure communication, digital signatures, and key exchange. RSA's security is based on integer factorization, while ECC's security relies on elliptic curve mathematics, offering higher security per bit.

## Key Concepts
- Public Key → Freely distributed key for encryption/verification.
- Private Key → Secret key for decryption/signing.
- Digital Signature → Verifies message authenticity and integrity.
- Key Exchange → Securely establishes a shared secret over insecure channels.
- Factoring Problem → Mathematical basis for RSA's security.
- ECDLP → Mathematical basis for ECC's security.
- PKI → System for managing digital certificates and public keys.
- Side-channel Attack → Exploits physical implementation details to extract secrets.
