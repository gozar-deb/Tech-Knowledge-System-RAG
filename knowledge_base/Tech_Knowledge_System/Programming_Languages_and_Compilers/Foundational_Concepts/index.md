## Quick Definition
Foundational concepts are the core principles governing programming language design, implementation, and execution. They cover syntax, semantics, data types, control flow, and the mechanisms compilers and interpreters use to transform code into runnable programs.

## Key Concepts
- Programming Paradigm → A fundamental style of programming, e.g., object-oriented or functional.
- Data Types → Classifications for values, defining their nature and permissible operations.
- Control Flow → The sequence in which program instructions are executed.
- Syntax → The grammatical rules dictating valid program structure.
- Semantics → The meaning and behavior of programming language constructs.
- Abstraction → Hiding complexity to present a simpler, higher-level view.
- Recursion → A function calling itself to solve a problem by breaking it into smaller instances.
- Type System → Rules that assign and manage types to ensure program correctness and safety.
