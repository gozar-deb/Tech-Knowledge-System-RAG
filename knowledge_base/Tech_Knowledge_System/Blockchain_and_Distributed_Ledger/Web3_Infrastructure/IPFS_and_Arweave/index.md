## Quick Definition
IPFS (InterPlanetary File System) is a decentralized peer-to-peer protocol for storing and sharing files, aiming to create a more robust and efficient web by distributing data across a network of nodes. Arweave is a decentralized storage network designed for permanent data storage, ensuring data integrity and availability over long periods through economic incentives.

## Key Concepts
- **Content Addressing (IPFS)** → Files are identified by their content hash (CID) rather than location.
- **Decentralized Network (IPFS)** → Files are distributed across a peer-to-peer network, eliminating single points of failure.
- **Merkle DAG (IPFS)** → A directed acyclic graph structure used to represent and link data blocks in IPFS.
- **Pinning (IPFS)** → The process of ensuring that a file remains available on the IPFS network by instructing a node to store it permanently.
- **Proof of Access (Arweave)** → Arweave's consensus mechanism that incentivizes miners to store and replicate data over time.
- **Blockweave (Arweave)** → Arweave's core data structure, a blockchain-like graph where each new block links to a previous block and a random older block.
- **Permaweb (Arweave)** → A permanent, decentralized web built on top of the Arweave network, hosting data that cannot be deleted or changed.
- **Storage Endowment (Arweave)** → A mechanism where a one-time fee covers the cost of permanent data storage by investing it and using the returns to pay miners.
