## Quick Definition
The Kimball and Inmon models are two distinct, widely adopted methodologies for designing data warehouses. Kimball focuses on a bottom-up, dimensional approach using data marts for agile development, while Inmon advocates a top-down, normalized enterprise data warehouse for data integrity and consistency.

## Key Concepts
- Kimball Model → Dimensional modeling, star/snowflake schemas, data marts, business-driven.
- Inmon Model → Normalized data warehouse, enterprise-wide, data integrity, subject-oriented.
- Dimensional Modeling → Data structured for analytical queries, separating facts from dimensions.
- Star Schema → Simple dimensional model with a central fact table and surrounding dimension tables.
- Normalization → Organizing data to reduce redundancy and improve data integrity.
- Data Mart → Subset of a data warehouse, tailored for specific business functions.
- ETL → Process of extracting, transforming, and loading data into a data warehouse.
- Data Governance → Policies and procedures for managing data availability, usability, integrity, and security.
