## Quick Definition
Relational databases organize data into structured tables, enforcing data integrity through predefined schemas and relationships. They utilize SQL for data manipulation and adhere to ACID properties, making them reliable for transactional workloads.

## Key Concepts
- Relational Model → Data structured in tables with rows and columns.
- SQL → Standard language for querying and managing relational databases.
- ACID Properties → Guarantees transaction reliability (Atomicity, Consistency, Isolation, Durability).
- Normalization → Reduces data redundancy and improves integrity by organizing tables.
- Primary Key → Uniquely identifies each record within a table.
- Foreign Key → Links records between tables, enforcing referential integrity.
- Indexing → Speeds up data retrieval by creating efficient lookup structures.
- Transactions → A single, indivisible unit of work in a database.
- Schema → The logical structure of the entire database.
- Concurrency Control → Manages simultaneous access to data to prevent inconsistencies.
