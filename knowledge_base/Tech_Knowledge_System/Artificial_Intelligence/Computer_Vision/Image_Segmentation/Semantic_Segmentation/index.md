## Quick Definition
Semantic segmentation is a computer vision technique that classifies each pixel in an image with a corresponding class label, providing a dense understanding of the scene. It enables precise object delineation and contextual interpretation, crucial for tasks requiring fine-grained image analysis.

## Key Concepts
- Pixel-level Classification → Assigning a class label to every pixel.
- Dense Prediction → Outputting a prediction for each pixel, not just bounding boxes.
- Encoder-Decoder Networks → Architectures that downsample for features and upsample for pixel-wise output.
- Ground Truth Masks → Manually labeled images used for training and evaluation.
- Contextual Understanding → Interpreting relationships between pixels and their surroundings.
- Boundary Refinement → Improving accuracy at object edges and borders.
