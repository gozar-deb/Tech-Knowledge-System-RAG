[CHUNK: DEFINITION]
The Completely Fair Scheduler (CFS) is the default CPU scheduler for the Linux kernel since version 2.6.23. It aims to provide a fair allocation of CPU time to all runnable processes, prioritizing fairness over strict time-slicing. CFS models an ideal, perfectly fair multi-tasking processor, ensuring each task receives a proportional share of CPU time.
