## Quick Definition
Foundational Concepts in Human-Computer Interaction (HCI) are the core theories, principles, and models that guide the design and evaluation of interactive systems. They focus on understanding human capabilities and limitations to create usable, useful, and enjoyable user experiences, forming the theoretical basis for effective interaction design.

## Key Concepts
- Usability → The ease with which users can achieve goals with a system.
- User-Centered Design (UCD) → An iterative design philosophy prioritizing user needs and feedback.
- Affordances → Visual cues that suggest how an object can be interacted with.
- Feedback → Information provided to the user about the outcome of their actions.
- Mental Models → Users' internal representations of how a system operates.
- Accessibility → Designing systems to be usable by people with diverse abilities.
- Gulf of Execution → The mismatch between user intentions and system actions.
- Gulf of Evaluation → The difficulty in interpreting system state after an action.
