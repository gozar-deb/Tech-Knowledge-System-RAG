## Quick Definition
Multi-Agent Systems (MAS) are computational frameworks where multiple autonomous intelligent agents interact to achieve complex goals. These systems leverage distributed intelligence and collaboration to solve problems that are beyond the capabilities of a single agent.

## Key Concepts
- Agent → An autonomous entity that perceives, decides, and acts within an environment.
- Environment → The context in which agents operate and interact.
- Interaction → Communication and coordination among agents.
- Emergent Behavior → System-level properties arising from local agent interactions.
- Coordination → Managing interdependencies to achieve collective objectives.
- Communication Protocols → Standardized rules for agent information exchange.
