## Quick Definition
Machine Translation (MT) is an Artificial Intelligence discipline focused on automatically converting text or speech from one natural language to another. It leverages computational models, primarily deep learning, to understand and reproduce meaning across linguistic boundaries without human intervention.

## Key Concepts
- Neural Machine Translation (NMT) → uses deep learning for high-quality, contextual translations
- Statistical Machine Translation (SMT) → relies on statistical models from bilingual data
- Rule-Based Machine Translation (RBMT) → employs linguistic rules and dictionaries
- Parallel Corpora → essential datasets of aligned texts for training MT models
- Encoder-Decoder Architecture → common NMT structure for processing and generating sequences
- Attention Mechanism → allows NMT models to focus on relevant source information
- Post-Editing → human refinement of machine-generated translations
- Transfer Learning → adapting pre-trained models to new domains or languages
