## Quick Definition
Access Control and Role-Based Access Control (RBAC) are security mechanisms that regulate who can perform what actions on database resources. RBAC simplifies permission management by grouping permissions into roles, which are then assigned to users, ensuring adherence to the principle of least privilege.

## Key Concepts
- Authentication → verifying user identity
- Authorization → defining permitted actions for authenticated users
- Roles → collections of permissions representing job functions
- Permissions → specific rights to interact with database objects
- Least Privilege → granting minimal necessary access rights
- Identity Management → processes for managing user identities and access
