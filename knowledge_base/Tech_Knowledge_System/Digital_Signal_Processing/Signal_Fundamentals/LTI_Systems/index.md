## Quick Definition
Linear Time-Invariant (LTI) systems are fundamental mathematical models in signal processing and control theory. They are characterized by linearity (superposition and homogeneity) and time-invariance (behavior independent of time shifts), making them highly predictable and analytically tractable.

## Key Concepts
- Linearity → System output is proportional to input, and superposition holds.
- Time-Invariance → System response to an input does not depend on when the input is applied.
- Impulse Response → The system's output to a Dirac delta input, fully defining the LTI system.
- Convolution → The mathematical operation combining input and impulse response to yield output.
- Transfer Function → Frequency-domain representation of an LTI system, often in Laplace or Z-transform.
- Stability → A system property where bounded inputs produce bounded outputs.
- Causality → A system property where output depends only on present and past inputs.
