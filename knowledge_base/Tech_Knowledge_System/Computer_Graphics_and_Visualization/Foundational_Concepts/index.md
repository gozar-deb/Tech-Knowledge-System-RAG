## Quick Definition
Foundational Concepts in Computer Graphics and Visualization are the core principles and techniques for creating, manipulating, and displaying visual information. They cover geometric transformations, rendering pipelines, and the mathematical basis for representing objects and light interaction in digital environments.

## Key Concepts
- Rasterization → converting vector data into pixels for display
- Vector Graphics → image representation using mathematical equations for scalable visuals
- 3D Transformations → operations like translation, rotation, and scaling in 3D space
- Projection → mapping 3D scenes to a 2D viewing plane
- Shading Models → algorithms for calculating surface color based on light interaction
- Texture Mapping → applying images to 3D model surfaces for detail
- Geometry Representation → methods for defining shapes (e.g., meshes, NURBS)
- Graphics Pipeline → sequence of steps from 3D data to 2D image
