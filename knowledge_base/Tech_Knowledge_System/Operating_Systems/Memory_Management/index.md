## Quick Definition
Memory management is a core operating system function that handles the allocation and deallocation of computer memory to running processes. It ensures efficient utilization, protects memory spaces from interference, and provides an abstraction layer for programs to access memory without knowing its physical layout.

## Key Concepts
- Virtual Memory → Allows processes to use more memory than physically available by swapping data to disk.
- Paging → Divides memory into fixed-size blocks (pages) for efficient storage and retrieval.
- Segmentation → Divides memory into logical, variable-sized segments corresponding to program units.
- Memory Protection → Prevents processes from accessing memory regions they are not authorized to use.
- Address Translation → Converts logical addresses generated by the CPU into physical memory addresses.
- Garbage Collection → Automatic reclamation of memory no longer in use by a program.

## Tools

| Tool | Type | Purpose |
|------|------|---------|
| MMU | Hardware | Translates virtual addresses to physical addresses |
| GDB | Debugger | Analyzes memory usage and detects leaks/corruptions |
| Valgrind | Profiler | Detects memory management and threading bugs |
| jemalloc | Library | General-purpose memory allocator, optimized for concurrency |
| Linux `free` command | Utility | Displays amount of free and used physical and swap memory |
