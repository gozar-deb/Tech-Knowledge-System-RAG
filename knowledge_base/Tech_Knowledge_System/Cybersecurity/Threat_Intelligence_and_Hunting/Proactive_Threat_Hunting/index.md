## Quick Definition
Proactive threat hunting is a cybersecurity discipline focused on actively searching for hidden threats within an IT environment that have evaded automated security controls. It involves human analysts using hypotheses and threat intelligence to uncover malicious activity before it causes significant harm, thereby reducing an attacker's dwell time.

## Key Concepts
- Dwell Time → The duration an attacker remains undetected in a system.
- Indicators of Compromise (IOCs) → Digital artifacts indicating a system compromise.
- Tactics, Techniques, and Procedures (TTPs) → Adversary behaviors and methods.
- Hypothesis-Driven Hunting → A structured approach to threat hunting based on assumptions.
- Behavioral Analytics → Analyzing patterns of activity to detect anomalies.
- Threat Intelligence → Contextual information about cyber threats.
