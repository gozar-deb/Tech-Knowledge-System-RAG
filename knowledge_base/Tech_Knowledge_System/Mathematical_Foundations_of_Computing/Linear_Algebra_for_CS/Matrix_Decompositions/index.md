## Quick Definition
Matrix decompositions are fundamental linear algebra techniques that factorize a matrix into a product of simpler matrices. This process reveals intrinsic properties of the original matrix, enabling efficient solutions for complex mathematical and computational problems across various scientific and engineering disciplines.

## Key Concepts
- Eigenvalue Decomposition (EVD) → Breaks down square matrices into eigenvalues and eigenvectors.
- Singular Value Decomposition (SVD) → Factors any matrix into singular values and singular vectors for data analysis.
- LU Decomposition → Decomposes a matrix into lower and upper triangular matrices for solving linear systems.
- QR Decomposition → Factors a matrix into an orthogonal and an upper triangular matrix, useful for least squares.
- Cholesky Decomposition → Efficiently factors symmetric, positive-definite matrices.
- Principal Component Analysis (PCA) → A statistical method using SVD for dimensionality reduction.
