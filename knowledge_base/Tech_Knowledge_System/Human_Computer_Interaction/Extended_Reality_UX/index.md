## Quick Definition
Extended Reality User Experience (XR UX) focuses on designing intuitive and engaging interactions within virtual, augmented, and mixed reality environments. It encompasses principles for spatial computing, sensory feedback, and minimizing cognitive load to create seamless immersive digital experiences.

## Key Concepts
- Spatial Interaction → How users navigate and manipulate objects in 3D space.
- Presence → The feeling of being physically in a virtual environment.
- Immersion → The degree to which an XR system encloses a user's senses.
- Haptic Feedback → Tactile sensations enhancing realism and interaction.
- Cognitive Load → Mental effort required for interaction in XR.
- Affordances → Design cues that suggest how an object can be used.
