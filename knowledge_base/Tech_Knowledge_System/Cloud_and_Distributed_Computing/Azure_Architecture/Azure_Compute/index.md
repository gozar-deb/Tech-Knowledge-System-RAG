## Quick Definition
Azure Compute provides scalable, on-demand computing resources in Microsoft's cloud, enabling users to run diverse applications and workloads. It offers a spectrum of services, from virtual machines for full infrastructure control to serverless functions for event-driven execution, abstracting away underlying hardware management.

## Key Concepts
- Virtual Machines (VMs) → Customizable virtualized servers for IaaS workloads.
- Containers → Portable, isolated environments for consistent application deployment.
- Serverless Computing → Event-driven code execution without server management.
- Azure Kubernetes Service (AKS) → Managed service for orchestrating containerized applications.
- Azure App Service → Platform for hosting web applications and APIs.
- Azure Batch → Service for running large-scale parallel computing jobs.
