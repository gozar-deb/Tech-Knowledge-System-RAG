## Quick Definition
Cognitive Science in HCI is an interdisciplinary field that applies cognitive psychology principles to design user interfaces and experiences. It focuses on understanding human perception, attention, memory, and problem-solving to create intuitive, efficient, and user-friendly interactive systems that align with human cognitive capabilities.

## Key Concepts
- Mental Models → Users' internal representations of how a system works.
- Cognitive Load → The mental effort required to use an interface, impacting performance.
- Attention → Selective focus on information, guided by interface design.
- Perception → Interpretation of sensory input from the interface.
- Memory → Storage and retrieval of information, crucial for recall and recognition.
- Problem-Solving → Cognitive process of achieving goals within a system.
- Usability → Ease of use and learnability of an interface.
