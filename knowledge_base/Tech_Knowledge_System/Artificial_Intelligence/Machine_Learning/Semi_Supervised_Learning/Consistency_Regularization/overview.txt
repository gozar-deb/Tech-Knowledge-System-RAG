[CHUNK: DEFINITION]
Consistency Regularization is a semi-supervised learning technique that enforces a model to produce similar outputs for perturbed versions of the same input. It leverages unlabeled data by encouraging the model's predictions to be consistent under various data augmentations or noise injections, thereby improving generalization and robustness.

[CHUNK: CORE_CONCEPTS]
- Perturbation: Intentional alteration of input data (e.g., noise, augmentation) to test model consistency.
- Consistency Loss: A regularization term that penalizes discrepancies between predictions on original and perturbed inputs.
