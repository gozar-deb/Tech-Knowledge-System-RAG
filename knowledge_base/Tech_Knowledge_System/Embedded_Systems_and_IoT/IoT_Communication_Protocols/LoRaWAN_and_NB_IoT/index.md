## Quick Definition
LoRaWAN (Long Range Wide Area Network) and NB-IoT (Narrowband-Internet of Things) are two prominent Low-Power Wide-Area Network (LPWAN) technologies designed for efficient, long-range communication of IoT devices, each optimized for different use cases and network infrastructures.

## Key Concepts
- LoRaWAN → A MAC layer protocol built on LoRa modulation for long-range, low-power, secure IoT communication.
- NB-IoT → A cellular-based LPWAN technology leveraging licensed LTE bands for reliable, low-power IoT connectivity.
- LPWAN → Low-Power Wide-Area Network, a category of wireless communication technologies designed for long-range, low-power IoT applications.
- Unlicensed Spectrum → Frequency bands that do not require a license for operation, used by LoRaWAN.
- Licensed Spectrum → Frequency bands requiring a license for operation, used by NB-IoT (cellular networks).
- Gateway/Base Station → Network infrastructure components that receive data from IoT devices and forward it to a network server.
- End Device → The IoT sensor or actuator that transmits and receives data using LPWAN protocols.
- Data Rate → The speed at which data can be transmitted; NB-IoT generally offers higher data rates than LoRaWAN.
- Battery Life → A critical metric for LPWAN devices, both technologies aim for extended battery life (years).
- Coverage → The geographical area over which a network can provide connectivity.
