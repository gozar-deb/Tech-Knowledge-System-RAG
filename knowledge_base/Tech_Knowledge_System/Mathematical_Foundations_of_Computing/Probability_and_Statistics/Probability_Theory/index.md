## Quick Definition
Probability theory is the mathematical study of randomness and uncertainty, providing a rigorous framework to quantify the likelihood of events and analyze the behavior of random variables. It forms the essential foundation for statistical inference, machine learning, and decision-making in uncertain environments.

## Key Concepts
- Sample Space → The set of all possible outcomes of a random experiment.
- Event → A specific outcome or a collection of outcomes from the sample space.
- Probability Measure → A function assigning a numerical likelihood to events.
- Random Variable → A variable whose value is determined by the outcome of a random phenomenon.
- Conditional Probability → The probability of an event given that another event has occurred.
- Independence → Events where the occurrence of one does not influence the other.
- Expected Value → The long-run average value of a random variable.
- Probability Distribution → A function describing the possible values and likelihoods of a random variable.
