## Quick Definition
Federated Learning is a distributed machine learning paradigm enabling collaborative model training across decentralized devices or organizations without direct data sharing. It prioritizes data privacy and reduces communication overhead by exchanging only model updates.

## Key Concepts
- Clients → Local data holders and trainers of model updates.
- Server → Orchestrates training, aggregates updates, and maintains the global model.
- Global Model → The shared, collaboratively trained machine learning model.
- Model Aggregation → Combining local model updates to refine the global model.
- Data Privacy → Core principle, ensuring raw data remains on local devices.
- Communication Efficiency → Reduces data transfer by sending only model parameters.
