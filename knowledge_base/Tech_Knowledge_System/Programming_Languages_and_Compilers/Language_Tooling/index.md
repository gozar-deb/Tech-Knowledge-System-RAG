## Quick Definition
Language tooling encompasses the software utilities and environments that facilitate the development, analysis, and manipulation of programming languages. These tools enhance developer productivity, ensure code quality, and streamline the software development lifecycle by providing features like code completion, debugging, and static analysis.

## Key Concepts
- **Integrated Development Environment (IDE)** → A comprehensive software suite that consolidates common developer tools into a single graphical user interface.
- **Compiler** → A program that translates source code written in one programming language into another language, typically machine code or bytecode.
- **Interpreter** → A program that directly executes instructions written in a programming or scripting language without requiring them to be compiled into machine language.
- **Debugger** → A tool used to test and debug target programs, allowing developers to inspect program state and execution flow.
- **Linter** → A static code analysis tool used to flag programming errors, bugs, stylistic errors, and suspicious constructs.
- **Language Server Protocol (LSP)** → A protocol used between a development tool (or IDE) and a language server to provide language-specific features like auto-completion, go-to-definition, and refactoring.
- **Build System** → Software that automates the creation of executable applications from source code.
- **Package Manager** → A collection of software tools that automates the process of installing, upgrading, configuring, and removing computer programs for a computer's operating system.
