## Quick Definition
Cryptography is the science of secure communication, protecting information from unauthorized access and tampering. It ensures data confidentiality, integrity, authentication, and non-repudiation through mathematical algorithms and protocols, forming the bedrock of digital security.

## Key Concepts
- Encryption → transforming data to hide its content
- Decryption → restoring encrypted data to its original form
- Hashing → creating a fixed-size digest for data integrity
- Digital Signatures → verifying sender identity and message authenticity
- Public-Key Cryptography → using distinct public and private keys for secure exchange
- Symmetric-Key Cryptography → employing a single shared secret key for encryption/decryption
- Key Management → secure handling of cryptographic keys throughout their lifecycle
- Cryptanalysis → studying methods to break cryptographic systems
