## Quick Definition
Image Signal Processing (ISP) is the application of digital signal processing methods to digital images. It focuses on manipulating visual data to improve quality, extract meaningful information, and prepare images for advanced analysis or display.

## Key Concepts
- Image Filtering → Modifying image pixels to enhance features or remove noise.
- Image Transforms → Converting spatial domain images to frequency domains for analysis or compression.
- Feature Extraction → Identifying unique and descriptive characteristics within an image.
- Image Segmentation → Dividing an image into regions or objects for simplified analysis.
- Image Compression → Reducing image file size while preserving visual fidelity.
- Image Enhancement → Improving the perceptual quality or interpretability of an image.
