## Quick Definition
Formal semantics is the mathematical study of the meaning of programming languages, providing rigorous methods to define how programs behave. It uses mathematical models to precisely describe execution, data manipulation, and program properties, eliminating ambiguity inherent in natural language specifications.

## Key Concepts
- Denotational Semantics → Maps language constructs to mathematical functions or objects.
- Operational Semantics → Describes program execution as a sequence of state transitions.
- Axiomatic Semantics → Defines meaning through logical assertions about program state changes.
- Type Theory → A formal system for classifying expressions to ensure program correctness.
- Program Verification → Proving a program meets its specification using formal methods.
- Lambda Calculus → A foundational formal system for computation based on function abstraction.
