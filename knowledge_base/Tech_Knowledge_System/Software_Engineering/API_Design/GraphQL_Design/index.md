## Quick Definition
GraphQL Design is the process of structuring a GraphQL API, defining its schema, and implementing data resolution logic. It enables clients to precisely request the data they need, optimizing data fetching and fostering flexible API evolution.

## Key Concepts
- Schema Definition Language (SDL) → Language for defining API structure and types
- Types → Define data shapes (objects, scalars, enums) within the schema
- Fields → Specific data points available on a type
- Resolvers → Functions that fetch data for schema fields
- Queries → Operations for reading data from the API
- Mutations → Operations for writing or modifying data in the API
- Subscriptions → Real-time data updates from the server
- Introspection → Server's ability to describe its own schema
