## Quick Definition
A feature store is a central system for managing and serving machine learning features. It standardizes feature definitions, ensures data consistency between training and inference, and facilitates feature reuse across multiple models and teams.

## Key Concepts
- Feature → A data point used as input for a machine learning model.
- Online Serving → Providing features for real-time model predictions with low latency.
- Offline Serving → Providing features for model training and batch predictions.
- Data Consistency → Ensuring the same feature values are used for both training and inference.
- Feature Lineage → Tracking the origin and transformations of features.
- Feature Versioning → Managing different iterations of features for reproducibility.
