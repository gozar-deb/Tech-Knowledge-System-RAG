## Quick Definition
Document stores are a type of NoSQL database that store data in flexible, semi-structured document formats, typically JSON or BSON. MongoDB is a popular open-source document database known for its scalability, high performance, and flexible schema, making it suitable for modern web applications and big data.

## Key Concepts
- Document → A record in MongoDB, stored as a BSON document with a flexible schema.
- Collection → A grouping of documents, similar to a table but without strict schema enforcement.
- Flexible Schema → Allows documents in a collection to have varying fields and structures.
- Sharding → Horizontal partitioning of data across multiple servers for scalability.
- Replica Set → A group of MongoDB instances that maintain the same data set for high availability.
- Aggregation Framework → A powerful tool for performing complex data processing and analysis operations.
