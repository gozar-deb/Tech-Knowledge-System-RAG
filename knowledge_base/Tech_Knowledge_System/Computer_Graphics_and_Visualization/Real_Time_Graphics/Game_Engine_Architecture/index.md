## Quick Definition
Game engine architecture is the underlying software framework that provides the essential tools and functionalities for creating video games and interactive applications. It integrates various subsystems like rendering, physics, and scripting to streamline development and manage complex real-time operations.

## Key Concepts
- Game Loop → The central processing cycle for game updates and rendering.
- Scene Graph → A hierarchical structure organizing objects within a virtual world.
- Rendering Engine → Component responsible for displaying visual elements on screen.
- Physics Engine → Simulates realistic interactions and movements of objects.
- Asset Pipeline → System for managing and optimizing game resources.
- Scripting System → Enables dynamic game logic through high-level code.
- Entity-Component-System (ECS) → A design pattern for flexible and performant game object composition.
- Data-Oriented Design (DOD) → An approach to optimize data layout for CPU cache efficiency.
