## Quick Definition
Consumer-Driven Contracts (CDC) is a testing methodology where consumers define the expected interactions with a service provider. This approach ensures that API changes do not break dependent services, fostering independent development and deployment in distributed systems.

## Key Concepts
- Contract → An agreement detailing expected API interactions and data formats.
- Consumer → The client or service utilizing another service's API.
- Provider → The service offering an API or functionality to consumers.
- Pact → A widely used framework for implementing CDC across various programming languages.
- Contract Test → An automated test verifying consumer-provider interaction against a defined contract.
- Stubbing/Mocking → Simulating provider responses for consumer testing without actual service calls.
