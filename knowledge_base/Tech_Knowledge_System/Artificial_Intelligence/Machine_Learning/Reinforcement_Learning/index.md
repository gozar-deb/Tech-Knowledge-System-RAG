## Quick Definition
Reinforcement Learning (RL) is a computational approach where an agent learns optimal behavior through interaction with an environment, receiving rewards for desirable actions. Its goal is to discover a policy that maximizes cumulative reward over time, making it suitable for sequential decision-making problems.

## Key Concepts
- Agent → The decision-making entity that learns.
- Environment → The external system providing states and rewards.
- State → A snapshot of the environment at a given moment.
- Action → An agent's choice that affects the environment.
- Reward → Immediate feedback on an action's desirability.
- Policy → The agent's strategy for choosing actions in states.
- Value Function → Estimates the long-term goodness of states or actions.
- Q-Learning → A popular algorithm for learning action-values.
- Markov Decision Process (MDP) → Mathematical model for RL problems.
- Exploration/Exploitation → Balancing trying new things vs. using known best options.
