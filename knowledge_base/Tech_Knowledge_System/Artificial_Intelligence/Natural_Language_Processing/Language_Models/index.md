## Quick Definition
Language Models are AI systems that process and generate human language by learning patterns from vast text datasets. They predict subsequent words or sequences, enabling tasks like translation, summarization, and conversational AI, primarily using deep learning architectures like transformers.

## Key Concepts
- Tokenization → Breaking text into manageable units for processing.
- Embeddings → Vector representations capturing semantic meaning of words/phrases.
- Transformers → Neural network architecture with self-attention, foundational for modern LMs.
- Pre-training → Initial broad training on large text corpora.
- Fine-tuning → Adapting a pre-trained model to a specific task.
- Prompt Engineering → Designing effective inputs to guide generative model outputs.
- Hallucination → Generating factually incorrect or nonsensical information.
- Attention Mechanism → Dynamically weighing input parts for relevance.
