## Quick Definition
Multi-Agent Reinforcement Learning (MARL) involves multiple intelligent agents learning to make decisions and interact within a shared environment. These agents can cooperate, compete, or act independently to achieve individual or collective goals, often leading to complex dynamic behaviors.

## Key Concepts
- Agent → An autonomous entity that perceives and acts in an environment.
- Environment → The shared world where agents interact and learn.
- Reward Function → A signal guiding agent learning towards desired outcomes.
- Policy → An agent's strategy mapping states to actions.
- Cooperative MARL → Agents collaborate to maximize a common reward.
- Competitive MARL → Agents vie against each other, often with opposing goals.
- Centralized Training Decentralized Execution (CTDE) → Training with global info, executing with local info.
- Partial Observability → Agents have incomplete information about the environment's true state.
- Game Theory → Mathematical framework for modeling strategic interactions among rational agents.
- Emergent Behavior → Complex patterns arising from simple agent interactions.
