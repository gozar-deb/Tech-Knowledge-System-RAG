## Quick Definition
SQL (Structured Query Language) is the standard language for managing and manipulating relational databases. It allows users to define, query, update, and control access to data, forming the foundation for data interaction in countless applications and systems.

## Key Concepts
- DDL (Data Definition Language) → Commands for defining database structure (e.g., CREATE TABLE).
- DML (Data Manipulation Language) → Commands for managing data within tables (e.g., SELECT, INSERT).
- DCL (Data Control Language) → Commands for managing user permissions (e.g., GRANT, REVOKE).
- TCL (Transaction Control Language) → Commands for managing database transactions (e.g., COMMIT, ROLLBACK).
- ACID Properties → Guarantees for reliable transaction processing (Atomicity, Consistency, Isolation, Durability).
- Normalization → Process to reduce data redundancy and improve data integrity in database design.
