## Quick Definition
Neural Machine Translation (NMT) architectures utilize deep learning models, primarily sequence-to-sequence networks with attention, to translate text between languages. These systems learn complex linguistic patterns directly from data, enabling more fluent and contextually accurate translations than traditional methods.

## Key Concepts
- Sequence-to-Sequence (Seq2Seq) → A general architecture for transforming input sequences into output sequences.
- Encoder-Decoder → The core components of Seq2Seq, where the encoder processes input and the decoder generates output.
- Attention Mechanism → Allows the decoder to selectively focus on parts of the input sequence during translation.
- Transformers → An attention-only architecture that revolutionized NMT by enabling parallel processing and superior performance.
- Recurrent Neural Networks (RNNs) → Earlier NMT models often used RNN variants like LSTMs or GRUs for sequential data.
- Subword Tokenization → A technique to handle rare words and manage vocabulary size by breaking words into smaller units.
- Beam Search → A decoding algorithm used to find the most probable translation sequence by exploring multiple options.
