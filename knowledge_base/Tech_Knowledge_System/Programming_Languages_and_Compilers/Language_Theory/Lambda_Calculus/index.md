## Quick Definition
Lambda Calculus is a formal system for expressing computation through function abstraction and application, developed by Alonzo Church. It serves as a foundational model for computability and is the theoretical underpinning of functional programming languages.

## Key Concepts
- Abstraction → defining functions (λx.M)
- Application → applying functions to arguments (MN)
- Beta-reduction → evaluating function applications
- Alpha-conversion → renaming bound variables
- Church Encoding → representing data using functions
- Combinators → functions built solely from abstraction and application
