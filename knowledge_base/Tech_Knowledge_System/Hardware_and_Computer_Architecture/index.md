## Quick Definition
Hardware and Computer Architecture is the discipline of designing and organizing the fundamental components of computer systems. It defines how processors, memory, and input/output devices interact to execute software, focusing on optimizing performance, power, and cost.

## Key Concepts
- CPU → The central component that executes program instructions.
- Memory Hierarchy → Layered storage system designed to balance speed and cost.
- Instruction Set Architecture (ISA) → The command language understood by a CPU.
- Pipelining → A technique to improve instruction throughput by overlapping execution stages.
- Parallel Processing → Executing multiple computations simultaneously to enhance performance.
- Cache Coherence → Maintaining consistent data across multiple local memory caches.
