## Quick Definition
Retrieval Augmented Generation (RAG) enhances Large Language Models (LLMs) by integrating external, up-to-date knowledge. It retrieves relevant information from a knowledge base to ground LLM responses, significantly reducing factual errors and improving contextual accuracy.

## Key Concepts
- Retrieval → fetching relevant data from external sources
- Generation → LLM's ability to create text based on context
- Knowledge Base → external repository of information, often a vector database
- Embeddings → numerical representations of text for semantic search
- Hallucination Mitigation → reducing LLM factual errors by providing external data
- Semantic Search → understanding query intent beyond keywords for better retrieval
- Chunking → breaking documents into smaller, meaningful units
- Re-ranking → prioritizing retrieved documents for optimal relevance
