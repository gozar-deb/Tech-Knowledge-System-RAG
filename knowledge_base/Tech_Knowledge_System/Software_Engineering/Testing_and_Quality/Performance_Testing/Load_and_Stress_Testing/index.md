## Quick Definition
Load testing evaluates system performance under anticipated user traffic, ensuring stability and responsiveness. Stress testing pushes the system beyond its normal limits to discover breaking points and validate recovery mechanisms.

## Key Concepts
- Load → simulated user activity or data volume
- Stress → exceeding operational limits to find failure points
- Throughput → rate of successful transaction processing
- Response Time → duration from request to system's first reply
- Concurrency → number of simultaneous users or requests
- Bottleneck → system component limiting overall performance
- Scalability → system's ability to handle increasing workload
- Breaking Point → load level causing significant system degradation or failure
