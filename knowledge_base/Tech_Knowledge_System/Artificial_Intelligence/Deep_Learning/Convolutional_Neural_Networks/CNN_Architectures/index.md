## Quick Definition
CNN Architectures are specific configurations of layers, connections, and hyperparameters within Convolutional Neural Networks. They are meticulously designed to optimize performance for various computer vision tasks, balancing accuracy with computational demands and efficiency.

## Key Concepts
- LeNet-5 → Early CNN for handwritten digit recognition.
- AlexNet → Landmark deep CNN, popularized ReLU and GPU training.
- VGGNet → Deep architecture using small 3x3 convolutional filters.
- ResNet → Solves vanishing gradient with residual connections.
- Inception → Multi-scale processing within a single module.
- DenseNet → Connects all layers directly to each subsequent layer.
- MobileNet → Efficient architectures for mobile and embedded devices.
