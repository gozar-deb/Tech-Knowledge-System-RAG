## Quick Definition
Unit testing validates individual code components in isolation, ensuring their correctness. Integration testing verifies the interactions and data exchange between different modules or services, confirming they function together as a complete system. Both are essential practices for building reliable and maintainable software.

## Key Concepts
- Unit Test → Verifies smallest testable parts of an application.
- Integration Test → Verifies interactions between integrated units or components.
- Test Double → Generic term for objects used to replace real dependencies in tests.
- Mock → A test double that records calls made to it, allowing verification of interactions.
- Stub → A test double that provides predefined answers to method calls during tests.
- Test-Driven Development (TDD) → Development methodology where tests are written before code.
