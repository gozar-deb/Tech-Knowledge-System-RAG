## Quick Definition
Approximation algorithms provide efficient, near-optimal solutions for computationally hard optimization problems, particularly those classified as NP-hard. They offer a guaranteed performance bound, ensuring the solution is within a known factor of the true optimum, making them essential when exact solutions are impractical or impossible to compute.

## Key Concepts
- NP-hard Problems → Optimization problems without known polynomial-time exact solutions.
- Approximation Ratio → Metric quantifying how close an algorithm's solution is to the optimal one.
- Performance Guarantee → A mathematical bound on the quality of an approximation algorithm's output.
- Polynomial Time → Algorithms with execution time bounded by a polynomial function of input size.
- Greedy Approach → A heuristic strategy making locally optimal choices at each step.
- Randomized Algorithms → Algorithms that incorporate randomness to achieve good approximate solutions.
- Local Search → Iterative improvement of a solution by exploring neighboring states.
