## Quick Definition
Advanced RAG Patterns are sophisticated architectural and algorithmic extensions to basic Retrieval Augmented Generation systems. They focus on enhancing the accuracy, relevance, and contextual integration of retrieved information to improve the quality and reliability of large language model outputs, particularly in complex scenarios.

## Key Concepts
- Multi-hop RAG → Iterative retrieval and generation for complex reasoning.
- Hybrid Retrieval → Combines diverse retrieval methods for comprehensive context.
- Self-Correcting RAG → LLM evaluates and refines its own responses against context.
- Adaptive RAG → Dynamically adjusts retrieval based on query or performance.
- Query Rewriting → Transforms queries for better alignment with knowledge bases.
- Re-ranking → Prioritizes most relevant documents from initial retrieval results.
- Agentic RAG → Integrates RAG within an autonomous agent framework.
- Recursive RAG → LLM recursively queries for deeper information.
