## Quick Definition
Message Passing Frameworks (MPFs) are the fundamental operational paradigm within Graph Neural Networks (GNNs), enabling nodes to iteratively exchange and aggregate information from their local neighborhoods. This iterative process facilitates the learning of comprehensive, context-rich representations for nodes and edges in graph-structured data.

## Key Concepts
- Message Function → Defines how information is generated by a node for its neighbors.
- Aggregation Function → Combines messages received from a node\'s neighbors into a single vector.
- Update Function → Integrates the aggregated message with a node\'s current state to produce a new state.
- Node Embeddings → Low-dimensional vector representations capturing a node\'s structural and feature context.
- Relational Inductive Biases → GNNs\' inherent ability to leverage graph structure for effective learning.
- Over-smoothing → A common issue where node representations become indistinguishable after many message passing layers.
