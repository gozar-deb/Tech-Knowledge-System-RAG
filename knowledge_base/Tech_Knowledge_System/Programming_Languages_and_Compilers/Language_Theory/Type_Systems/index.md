## Quick Definition
Type systems are formal rules that assign types to programming constructs, ensuring operations are valid for their data. They enhance program reliability by detecting errors early and provide a framework for reasoning about program behavior.

## Key Concepts
- Static Typing → Type checking at compile-time for early error detection.
- Dynamic Typing → Type checking at run-time for flexibility and late binding.
- Type Inference → Automatic deduction of data types by the compiler.
- Type Safety → Guarantee that a program will not encounter type errors.
- Polymorphism → Ability of code to operate on values of different types.
- Generics → Parameterized types for writing reusable, type-agnostic code.
- Subtyping → A relationship where one type can substitute another.
- Type Erasure → Process of removing type information at compile-time.
