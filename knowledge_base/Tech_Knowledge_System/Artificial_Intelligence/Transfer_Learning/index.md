## Quick Definition
Transfer Learning is a machine learning technique that reuses a model trained on one task as a starting point for a different but related task. This approach significantly reduces training time and data requirements, leveraging knowledge from large datasets to improve performance on new problems.

## Key Concepts
- Pre-trained Model → A model already trained on a large dataset for a general task.
- Fine-tuning → Adapting a pre-trained model's weights to a specific new dataset and task.
- Feature Extraction → Using a pre-trained model to generate features for a new classifier.
- Domain Adaptation → Adjusting models to perform well across different data distributions.
- Inductive Transfer → Transferring knowledge when source and target tasks differ.
- Catastrophic Forgetting → The tendency of neural networks to forget old knowledge when learning new tasks.
