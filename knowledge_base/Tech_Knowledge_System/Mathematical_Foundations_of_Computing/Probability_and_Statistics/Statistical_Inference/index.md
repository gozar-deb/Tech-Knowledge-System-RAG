## Quick Definition
Statistical inference is the scientific process of deducing properties of an underlying probability distribution by analyzing data. It allows us to make informed judgments about populations based on sample observations, quantifying the uncertainty of these conclusions.

## Key Concepts
- Hypothesis Testing → A formal method to test a claim or hypothesis about a population parameter.
- Estimation → The process of calculating approximate values for unknown population parameters.
- Confidence Interval → A range of values within which a population parameter is expected to lie with a certain probability.
- P-value → The probability of observing results as extreme as, or more extreme than, the observed results, assuming the null hypothesis is true.
- Statistical Significance → The likelihood that a result is not due to random chance, often determined by a p-value below a chosen alpha level.
- Type I and Type II Errors → Errors in hypothesis testing: false positive (Type I) and false negative (Type II).
