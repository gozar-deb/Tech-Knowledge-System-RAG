## Quick Definition
DDoS mitigation involves strategies and tools to protect online services from Distributed Denial of Service attacks. It focuses on identifying and filtering malicious traffic to ensure the continuous availability and performance of targeted systems.

## Key Concepts
- Volumetric Attacks → Overwhelm bandwidth with high traffic volume.
- Protocol Attacks → Exploit weaknesses in network protocols like SYN floods.
- Application Layer Attacks → Target specific application vulnerabilities to exhaust resources.
- Traffic Scrubbing → Rerouting and cleaning traffic through specialized centers.
- Anomaly Detection → Identifying unusual traffic patterns indicative of an attack.
- Rate Limiting → Restricting request frequency from specific sources.
