## Quick Definition
Processing-in-Memory (PIM) is an architectural paradigm that integrates computational capabilities directly into or near memory modules. Its primary goal is to mitigate the "memory wall" bottleneck by reducing the energy and latency costs associated with moving data between processors and main memory, thereby boosting performance for data-intensive applications.

## Key Concepts
- Memory Wall → The performance gap between fast CPUs and slower memory access.
- Near-Memory Computing → Processing logic placed physically close to memory.
- In-Memory Computing → A broader concept where computations occur on data in memory.
- Data Locality → Maximizing computations on data where it resides to minimize movement.
- Hybrid Memory Cube (HMC) → A stacked memory architecture with integrated logic.
- High Bandwidth Memory (HBM) → Stacked DRAM with high throughput, often co-packaged with logic.
