## Quick Definition
Temporal Transformers are deep learning models that adapt the Transformer architecture to time-series data. They use self-attention to model complex dependencies across time, excelling in tasks like forecasting and anomaly detection by processing sequences efficiently and in parallel.

## Key Concepts
- Self-Attention → mechanism to weigh importance of sequence elements.
- Multi-Head Attention → parallel attention for diverse feature subspaces.
- Positional Encoding → encodes sequence order information.
- Encoder-Decoder → common architecture for sequence-to-sequence tasks.
- Time Series Embedding → transforms raw data for Transformer input.
- Causal Masking → prevents decoder from seeing future data.
