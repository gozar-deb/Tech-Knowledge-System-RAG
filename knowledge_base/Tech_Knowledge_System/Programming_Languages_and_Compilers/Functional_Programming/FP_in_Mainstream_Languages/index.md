## Quick Definition
Functional Programming (FP) in mainstream languages involves applying FP principles like immutability, pure functions, and higher-order functions within languages not exclusively designed for FP. This approach leverages language features such as lambda expressions and stream APIs to write more declarative, concise, and testable code.

## Key Concepts
- Pure Functions → Functions that produce the same output for the same input and have no side effects.
- Immutability → Data structures cannot be changed after creation, promoting predictable state.
- Higher-Order Functions → Functions that take other functions as arguments or return them as results.
- First-Class Functions → Functions treated as ordinary values, assignable to variables, passed as arguments, and returned from other functions.
- Declarative Programming → Focusing on *what* to achieve rather than *how* to achieve it.
- Side Effects → Any state change or interaction with the outside world beyond returning a value.
