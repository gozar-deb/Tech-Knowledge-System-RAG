## Quick Definition
DevOps is a cultural and technical movement that integrates software development and IT operations to streamline delivery and improve quality. Site Reliability Engineering (SRE) is a specific implementation of DevOps, applying software engineering principles to operations tasks to ensure high reliability and scalability of systems.

## Key Concepts
- CI/CD → Automated software delivery pipeline for faster releases.
- Infrastructure as Code (IaC) → Managing infrastructure through machine-readable definition files.
- Observability → Understanding system internals from external data like metrics, logs, and traces.
- Service Level Objectives (SLOs) → Measurable targets for service performance and reliability.
- Error Budget → The acceptable amount of system unreliability within a given period.
- Toil → Repetitive, manual, automatable operational work that adds no lasting value.
- GitOps → Using Git as the single source of truth for declarative infrastructure and application deployment.
- Blameless Post-mortems → Incident analysis focused on systemic improvements, not individual blame.
