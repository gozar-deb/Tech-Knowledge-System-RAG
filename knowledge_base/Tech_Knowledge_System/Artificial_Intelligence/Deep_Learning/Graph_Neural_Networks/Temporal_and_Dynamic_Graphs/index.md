## Quick Definition
Temporal and Dynamic Graphs extend traditional graph theory and Graph Neural Networks (GNNs) to model systems where relationships and attributes change over time. This field focuses on capturing the evolution of graph structures and node/edge features, enabling analysis of sequential and time-dependent interactions within complex networks.

## Key Concepts
- Dynamic Graph → A graph whose structure or attributes evolve over time.
- Temporal Graph → Edges are timestamped, indicating the time of interaction.
- Snapshot-based GNNs → Process dynamic graphs as sequences of static snapshots.
- Continuous-Time GNNs → Directly model event streams and continuous interactions.
- Spatio-Temporal GNNs → Handle both spatial (graph) and temporal (time-series) dependencies.
- Node Evolution → Changes in node features or presence over time.
- Edge Dynamics → Formation, deletion, or weight changes of connections.
- Temporal Attention → Mechanisms to weigh past interactions for current state prediction.
