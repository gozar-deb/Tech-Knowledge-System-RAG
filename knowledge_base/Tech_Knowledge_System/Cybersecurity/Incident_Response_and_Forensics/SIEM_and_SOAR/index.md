## Quick Definition
SIEM (Security Information and Event Management) centralizes security data for threat detection and compliance. SOAR (Security Orchestration, Automation and Response) automates and orchestrates incident response workflows, enhancing the efficiency and speed of security operations.

## Key Concepts
- SIEM → Aggregates and analyzes security logs and events.
- SOAR → Automates and orchestrates security incident response.
- Log Management → Collection, storage, and analysis of log data.
- Event Correlation → Identifying security incidents from disparate events.
- Playbooks → Automated, predefined sequences of actions for incident response.
- Automation → Performing security tasks without human intervention.
- Orchestration → Coordinating multiple security tools and systems.
- Incident Response → Structured process for managing security breaches.
