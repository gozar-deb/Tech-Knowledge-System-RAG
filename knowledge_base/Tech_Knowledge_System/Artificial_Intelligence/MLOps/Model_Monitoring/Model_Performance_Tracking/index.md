## Quick Definition
Model performance tracking is the continuous oversight of deployed machine learning models to ensure their ongoing effectiveness and reliability. It involves monitoring key metrics to detect issues like data or concept drift, which can lead to a decline in model accuracy and impact operational outcomes.

## Key Concepts
- Data Drift → Changes in input data distribution affecting model accuracy.
- Concept Drift → Changes in the relationship between features and target, invalidating model assumptions.
- Model Degradation → Decline in model performance over time.
- Evaluation Metrics → Quantitative measures (e.g., F1-score, RMSE) to assess model quality.
- Alerting Systems → Automated notifications for performance anomalies.
- Retraining Strategies → Methods to update models with new data to restore performance.
- Baseline Performance → Reference performance established during model validation.
- Model Observability → Ability to understand model behavior through its outputs and metrics.
