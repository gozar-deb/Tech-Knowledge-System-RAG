## Quick Definition
Passwordless authentication is a modern security approach that removes the need for traditional passwords, replacing them with more secure and convenient methods like biometrics, FIDO security keys, or one-time codes. It significantly reduces the risk of phishing and credential theft while enhancing user experience.

## Key Concepts
- FIDO → An open standard for strong, phishing-resistant authentication.
- WebAuthn → A browser API enabling FIDO authentication on the web.
- Biometrics → User verification via unique physical characteristics (fingerprint, face).
- Magic Links → Single-use URLs for email-based authentication.
- OTP → Time-sensitive codes for one-time login.
- Phishing Resistance → Inherent security against credential harvesting attacks.
