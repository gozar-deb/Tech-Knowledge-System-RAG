## Quick Definition
Terraform Cloud is HashiCorp's managed platform for Terraform, providing a collaborative workspace for teams to manage Infrastructure as Code (IaC) workflows. It offers remote state management, policy enforcement, and version control integration to enhance automation and governance.

## Key Concepts
- Remote State: Centralized and secure storage for Terraform state files, enabling team collaboration.
- Workspaces: Logical environments for organizing and managing infrastructure configurations.
- Run Environment: The execution context where Terraform operations (plan, apply) are performed.
- Policy as Code: Using Sentinel to define and enforce governance policies on infrastructure changes.
- Private Registry: A repository for sharing and reusing private Terraform modules within an organization.
- Version Control System (VCS) Integration: Connecting Terraform Cloud to Git repositories for automated runs.
